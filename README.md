# 📈 TradingAgents: Multi-Agent AI-Powered Trading & Portfolio Dashboard

TradingAgents is a state-of-the-art investment decision-making dashboard powered by **FastAPI** and **LangGraph**. It orchestrates a multi-agent AI system where specialized agents (analysts, researchers, risk debaters, and portfolio managers) collaborate, debate, and verify information to produce final trading decisions and optimize simulated portfolios.

The platform supports technical analysis, market sentiment (Reddit/StockTwits), global news, fundamental balance sheets, macroeconomic reports, options chains, and quantitative factors. It features a modern, glassmorphic dark-themed UI with real-time analysis streaming over WebSockets, paper trading simulation, and automated cron-based runs.

> [!NOTE]
> For a deep dive into the system mechanics, directories, settings, and agent details, please refer to the documentation starting with [docs/introduction.md](docs/introduction.md).

---

## 🚀 Key Features

*   **Multi-Agent Decision Workflows:** A state-machine structured via LangGraph where market analysts fetch data, bull/bear researchers debate investment theses, risk agents argue safety parameters, and a portfolio manager makes the final trade execution.
*   **Modular Analyst Plugins:** Contains 9 dynamically registered analysts: Market (Technical), Social Sentiment, News, Fundamentals, Macroeconomics, Options Chain, Quantitative factor, Earnings call, and Performance Review.
*   **WebSocket Event & Report Streaming:** Real-time progress streaming of graph node executions and progressive streaming of report sections as they are generated by LLMs.
*   **Broad LLM Integrations:** Direct native support for OpenAI (GPT-4o, o1/o3), Anthropic (Claude 3.5 Sonnet), Google Gemini (2.0/2.5), DeepSeek, xAI Grok, Ollama (Local), and Azure OpenAI.
*   **Simulation & Paper Trading:** Track portfolios, cash balances, manage open orders, view transaction histories, and test agent strategies in a safe sandbox.
*   **Cron Scheduler & Alerts:** Set recurring background runs for watchlist assets via APScheduler, and trigger alerts or webhooks based on signal changes.
*   **Linux Installation & Self-Updater:** Fully automated shell setup script for system dependencies, PostgreSQL, Python venv, and systemd. Includes a secure one-click web update mechanism that runs Git pull, re-compiles the frontend, and restarts services.
*   **Frontend Localization (i18n):** Built-in multi-language dashboard interface supporting English (default) and Turkish with an easy-to-use toggle component, persisting language choice in `localStorage`.

## 🛠️ Tech Stack

*   **Backend:** Python 3.10+, FastAPI, SQLAlchemy (Asyncio / asyncpg), PostgreSQL, APScheduler, LangGraph, LangChain Core.
*   **Frontend:** React (TypeScript), Vite, TailwindCSS (custom dark glassmorphism theme), Recharts (interactive charts).
*   **Data Providers:** yFinance, Alpha Vantage, Reddit API, SearXNG search engine.

## ⚙️ Installation & Getting Started

### Method 1: One-Click Linux Sunucularda Kurulum (Recommended for Linux servers)

If deploying to a Debian/Ubuntu or Fedora/RHEL server, run the automated installation script to configure system packages, Node.js, PostgreSQL, a Python virtual environment, dynamic `.env` secrets, and a systemd daemon:

```bash
sudo bash deploy/install.sh
```

Upon completion, access the credentials and login URL displayed on the console.

#### To load LLM API Keys:
Edit the generated `.env` file and restart the service:
```bash
sudo nano .env # Insert your API keys (e.g. OPENAI_API_KEY, ANTHROPIC_API_KEY)
sudo systemctl restart tradingagents
```

---

### Method 2: Docker Compose

Ensure Docker and Docker Compose are installed on your target machine:

1.  Copy `.env.example` to `.env` and fill in your details:
    ```bash
    cp .env.example .env
    ```
2.  Launch the environment:
    ```bash
    docker-compose up -d --build
    ```
3.  Access the React web client at `http://localhost:5173` and the FastAPI backend at `http://localhost:8000`.

---

### Method 3: Manual Developer Setup

To set up a local development workspace manually:

#### 1. Setup PostgreSQL Database
Ensure a local PostgreSQL instance is running, create a database named `tradingagents`, and configure the connection string inside your `.env` as `DATABASE_URL`.

#### 2. Install & Start Backend
1.  Initialize a virtual environment:
    ```bash
    python -m venv .venv
    # On Windows:
    .venv\Scripts\activate
    # On Linux/macOS:
    source .venv/bin/activate
    ```
2.  Install dependencies:
    ```bash
    pip install -r backend/requirements.txt
    ```
3.  Configure your local `.env`.
4.  Run the API server:
    ```bash
    uvicorn backend.main:app --reload --port 8000
    ```

#### 3. Install & Start Frontend
1.  Navigate to the frontend folder and install packages:
    ```bash
    cd frontend
    npm install
    ```
2.  Boot up the Vite dev server:
    ```bash
    npm run dev
    ```
3.  Visit `http://localhost:5173` in your browser.

## 📝 Key Environment Variables (.env)

The following configurations can be loaded into your `.env` file:

| Key | Description | Default / Example |
| :--- | :--- | :--- |
| `SECRET_KEY` | Hexadecimal key used to secure JWT access tokens | `secret-token-key-string` |
| `DATABASE_URL` | Async PG database URL | `postgresql+asyncpg://user:pass@host:5432/db` |
| `OPENAI_API_KEY` | OpenAI API key (optional) | `sk-proj-...` |
| `ANTHROPIC_API_KEY`| Anthropic Claude API key (optional) | `sk-ant-...` |
| `GOOGLE_API_KEY` | Google Gemini API key (optional) | `AIzaSy...` |
| `SEARXNG_URL` | URL of the SearXNG meta-search engine | `http://localhost:8080` |
| `ADMIN_USERNAME` | First administrator username | `admin` |

## 🔄 Automated Self-Updates

The platform features a secure, decoupled mechanism to automatically update itself from the web dashboard:
*   [update_service.py](backend/services/update_service.py) periodically fetches the remote repo commits (`origin/main`).
*   If an update is available, a notification banner is displayed on the UI.
*   Upon clicking "Update", FastAPI triggers a separate, non-blocking one-shot systemd service `tradingagents-update.service`. This service executes `git pull`, `pip install`, and `npm run build` as an unprivileged user, and performs a safe root restart of the main service.
